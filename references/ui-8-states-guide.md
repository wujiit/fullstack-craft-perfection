# UI 8 态生命周期完整实现指南 (UI 8-State Lifecycle Specification)

在国际顶级获奖级（Awwwards / Webby / FWA）数字产品中，界面的灵魂在于**全状态的推敲与连续性反馈**。任何交互元素或承载异步数据的模块，必须推敲并完整实现以下 8 态生命周期闭环。

---

## 1. Default State（默认精致态）
- **核心目标**：建立清晰的第一视觉落点，排版留白呼吸自然。
- **实现要点**：
  - 容器严格使用 Design Tokens 提供的表面色（如 `--color-bg-surface`）与微透边框（`--color-border-subtle`）；
  - 字阶与色彩对比严格遵循可读性规范，主要信息、辅助说明、元数据层级分明；
  - 初始状态禁止过载刺眼的饱和纯色。

---

## 2. Hover State（微悬浮与环境光泽态）
- **核心目标**：为鼠标移动提供微妙、灵动的物理感知反馈。
- **实现要点**：
  - **GPU 合成层**：仅使用 `transform: translateY(-2px) scale(1.01)`，严禁修改 `top`/`margin`；
  - **环境光漫反射**：微提升边框高光（`--color-border-highlight`），增加微光阴影（`--shadow-glow`）；
  - **缓动过渡**：强制绑定 `cubic-bezier(0.16, 1, 0.3, 1)`（`--ease-out-expo`），杜绝突兀跳变。

---

## 3. Active / Press State（按压弹性微形变态）
- **核心目标**：提供触觉般的按压物理反馈（Tactile Feedback）。
- **实现要点**：
  - 点击发生时，瞬时轻微回缩：`transform: translateY(0px) scale(0.98)`；
  - 过渡时间缩短至 `100~150ms`，带来干脆利落的机械轴般的按压质感。

---

## 4. Focus-Visible State（键盘无障碍聚焦态）
- **核心目标**：兼顾 WCAG 无障碍访问与现代高阶审美。
- **实现要点**：
  - 必须使用 `:focus-visible` 选择器（避免鼠标点击时弹出多余黑边框）；
  - 呈现双层环状发光轮廓：`outline: 2px solid var(--color-accent-primary); outline-offset: 2px;`。

---

## 5. Skeleton / Loading State（流光呼吸骨架屏态）
- **核心目标**：在数据加载在途时消除用户等待焦虑，保持版式结构稳定，杜绝粗糙的单体 Spinner 导致布局位移（CLS）。
- **实现要点**：
  - 骨架屏轮廓严格 1:1 复刻最终内容的文字行、卡片与媒体尺寸；
  - 背景采用平滑渐变流光动画（Shimmer）：
    ```css
    @keyframes shimmer {
      0% { transform: translateX(-100%); }
      100% { transform: translateX(100%); }
    }
    ```
  - 流光元素使用硬件加速伪元素叠加在基底上，流动周期推荐 `1.5s`。

---

## 6. Empty State（高品味空数据态）
- **核心目标**：杜绝丑陋的“暂无数据”文字空白弃页，转化为友好的交互引导。
- **实现要点**：
  - 配置精致的微矢量轮廓插画或抽象几何光效；
  - 给出专业友好的文案提示，并附带明确的行动指引（CTA，如“立即创建”、“重置筛选”按钮）。

---

## 7. Error / Fallback State（友好容错与重试态）
- **核心目标**：网络异常、API 崩溃或图片 404 时，提供尊重的安抚与自愈通道。
- **实现要点**：
  - 严禁向用户直接抛出堆栈报错、HTTP 500 或破损红叉；
  - 提供内嵌式错误卡片，给出通俗易懂的排查提示；
  - 必须内嵌**一键重试（Retry）按钮**，且重试时具备在途 Loading 防连击保护。

---

## 8. Disabled State（优雅非激活态）
- **核心目标**：清晰表达当前不可用状态，同时保留界面质感分层。
- **实现要点**：
  - 透明度合理降级（如 `opacity: 0.45;`），光标设置为 `cursor: not-allowed;`；
  - 彻底阻断点击与悬停事件：`pointer-events: none;`（若需展示 Tooltip 提示不可用原因，外层可包裹受控容器）；
  - 依然保持低反差边框轮廓，防止组件“直接消失”破坏整体网格平衡。

---

## 9. 状态图标工程化原则 (Zero-Emoji Standardization)
- **杜绝原生 Emoji 滥用**：在 Empty（空状态）、Error（报错重试）、Success（成功状态）以及各个交互状态指示标签中，**绝对禁止直接使用原生 Emoji 字符（如 ❌, ⚠️, 📦, 💡, ⏳）充当状态图标**；
- **跨端一致性与质感**：原生 Emoji 在 Windows/Mac/iOS/Android 及不同浏览器下渲染风格极度割裂，低版本系统极易显示为乱码方块（□），质感廉价；
- **正规工程方案**：统一使用轻量标准矢量 `<svg>` 或可配置的第三方矢量图标库，支持随主题色 CSS 变量自适应，确保在任意分辨率与高刷屏下清晰细腻。
